# Product Hunt

**Name:** Kanto

**Tagline** (60 characters at most):

> Accessible web components in your colours, in any framework

**Description** (260 characters at most):

> Eighty components for dashboards, admin tools and forms — tables, date
> pickers, a command palette, charts. Standard custom elements, so they run in
> React, Vue, Angular, Svelte or plain HTML. Theme them in one line. Free and
> open source.

**Topics:** Developer Tools, Design Tools, Open Source, User Experience
